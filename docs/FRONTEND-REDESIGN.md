# 前端改版與驗證

## 現在的使用流程

首頁以「分身有術，遇事有路」介紹跨場景平台，右側連續波形營造經驗流動的氛圍；旅行、轉職與生活放在下一區塊。使用者從「找我的神隊友」探索服務，查看介紹、模型與費率，填寫需求並確認本次預算，再連接錢包開始使用。

對話頁下方是「分身的足跡」：工作進展、工具使用與鏈上紀錄合在同一條活動列表，預設顯示最近三筆，可展開全部並點開交易。對話、費用與結束入口沿用既有流程。結束後以彈窗呈現費用與評分，提供探索其他服務、查看紀錄兩個去向；也能關閉彈窗繼續回看對話。

「我的錢包」只提供地址、可用餘額、更新與連接／中斷。未連接時直接提供連接按鈕；預算仍在每次服務開始前設定。測試模式同時提供自己的瀏覽器錢包及既有兩個測試帳號。

提供者從達人工作室上架服務，自行撰寫 Skill 指引，或匯入包含 SKILL.md 的資料夾。頁面說明 name、description、Markdown 指引與目前匯入行為，並提供 [Agent Skills 官方格式](https://agentskills.io/specification) 連結。本站會將其他 Markdown（README.md 除外）另建服務，不會執行 scripts 或載入其他附件。模型顯示在服務概要，不必打開進階資料才找得到。

## 人工確認

1. 打開 `http://localhost:3000`，看分身展開，再往下看創作者邀請。預期平台定位清楚、大標有重量，沒有零碎便箋旁白。
2. 開啟「我的錢包」。在已安裝 MetaMask 的瀏覽器可選自己的錢包；也可用本機測試帳號。進入「查看餘額」後，預期看到地址、test USDC 餘額與更新操作。
3. 探索一份服務。預期模型直接顯示，預算在開始服務的表單中設定。
4. 進入「我的紀錄」，回看已結束的服務。預期在對話下方看到活動足跡，能展開與點開鏈上交易；按「查看結算結果」開啟彈窗，Escape 可關閉。
5. 進入「達人工作室 → 上架我的服務」。預期能理解 Skill 指引與資料夾匯入方式，不必猜測要填什麼。只檢查畫面時不需送出上架。

## 2026-09-06 實測修正

錢包選單優先列出瀏覽器偵測到的錢包，隱藏重複的通用入口；測試錢包需展開「開發測試錢包」。支援 EIP-5792 atomic 的錢包將授權與建立服務合併，含登入共兩次確認；不支援者保留分開交易。批次送出失敗不自動改送另一組交易。

模型 503 曾觸發前端自動結束及退款，造成追問後兩次交易與評分彈窗。現在錯誤保留對話，由使用者重試或自行結束。有效登入授權沿用，不需要每次追問簽名。後端允許 active 服務重試，最新執行失敗時不續送 proof；成功重試後恢復。既有合約在 proof 逾時後不能恢復，登入授權也仍有期限；這些情況不等同一般追問。

鏈上 getAgent(3) 確認「回復你好」提供者費率為 0，顯示的 0.000300 USDC／秒全屬平台費；getAgent(5) 的作者費率為 0.019700。沒有替既有零費率服務補寫收入。金額改六位小數，最小單位作者費率與同帳號自用結算有回歸測試。

驗證：後端測試 43 項、前端測試 15 項通過；型別檢查通過。瀏覽器 fixture 重現 503 後重試成功，交易與簽名次數皆 0。1440×1000 四段 sticky、390×844 無橫向溢出。錢包批次以 fixture 驗證，未代替使用者進行真實錢包交易或 LLM 付費測試。
