# 分身有術
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
需要把他人經驗用在自身情況的使用者；希望上架經驗與方法的服務提供者。旅行、轉職、在地生活都是場景，平台不限定旅行。

## Product Purpose
讓人們按需使用達人經驗，透過 AI 依照服務設定回應需求與追問。

## Capabilities and Constraints
沿用搜尋、分類、服務上架、需求輸入、對話、紀錄、評分、錢包、預算與結算。現行 Base Sepolia、test USDC、按秒計費、停止退款保持不變。依後續回饋移除前端獨立 x402 查詢頁與專用依賴，既有後端 API 保留。暫停續用不支援。即時費用為估算，以合約結算為準。
本次只改前端體驗、流程、文案與視覺；允許小型高效益的易用性改善。不新增決策板、結構化摘要、作者資料系統或付款機制。

## Brand Commitments
繁體中文、台灣原生語感，瑞士排版秩序與台灣溫暖。名稱與平台定位不變。文案強調使用者的情況、服務能協助什麼與清楚的操作結果。

## Evidence on Hand
根目錄 README.md、docs/PITCH.md、現行服務資料。作者名稱、服務內容及評價依 API 原始資料，不虛構資歷、評價、照片或成果。
