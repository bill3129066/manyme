# 前端改版與驗證

## 使用流程

首頁先說明「把過來人的經驗，用在你自己的情況」，旅行只是其中一個使用情境。使用者進入探索服務，以搜尋或既有分類找到服務，讀懂內容、費率與使用方式後，填寫需求並確認本次預算。連接錢包與開始服務沿用既有合約流程。

服務開始後，以對話為主要畫面。使用者補充條件、追問；費用與「結束並結算」保持可見。技術工作紀錄與鏈上活動可另外展開。結束後回看紀錄與結算費用；清除畫面可以復原。關閉分頁不等於結束計費。

提供者從達人工作室進入上架頁，先填服務名稱、介紹、引導方法與費率，選擇可用模型；需求範本與回應參數放在進階設定。保留資料夾匯入、內容精簡、上架與收入領取的原有能力。

## 設計範圍

採繁體中文、Noto Sans TC、紙色、磚紅與深綠，透過對齊、字級與細分隔線建立層級。共用導覽、首頁、探索、詳情、上架、對話、紀錄、工作室、錢包說明與單次查詢均已更新。詳細規則見 [設計系統](../frontend/DESIGN.md)，產品邊界見 [產品說明](../frontend/PRODUCT.md)。

後端、ABI、合約、簽章與付款 API 未修改。舊 `/skills/[id]` 保留相容頁面，未整頁改版。

## 人工確認

1. 打開 `http://localhost:3000`，從「找找適合我的服務」進入列表。預期先理解平台用途，再看到真實服務內容。
2. 選一個服務，閱讀費率、填需求與預算。預期費用、測試網及開始條件清楚，手機不需要左右捲動。
3. 連接測試使用者錢包後，進入「我的紀錄」並回看已結束的服務。預期可以閱讀對話、查看結算、清除畫面後復原。
4. 進入「達人工作室 → 上架我的服務」，檢查用字與填寫順序。只檢查介面時不需送出上架。
